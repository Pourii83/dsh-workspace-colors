# رنگ فضاهای کاری DSH

[English](README.md) | **فارسی**

یک پلاگین ماندگار برای [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) که به
هر فضای کاری (workspace) در نوار کناری یک رنگ دلخواه می‌دهد تا پروژه‌ها در یک نگاه قابل تشخیص
باشند.

<img src="icon.svg" width="72" height="72" alt="آیکون پلاگین">

## چرا

نوار کناری، نشست‌ها را زیر نام فضای کاری گروه می‌کند؛ با چند پروژهٔ باز، فهرست یکدست و بی‌تمایز
به نظر می‌رسد. این پلاگین یک لایهٔ برگشت‌پذیر روی هاست اضافه می‌کند: یک صفحهٔ تنظیمات، یک رنگ
ذخیره‌شده برای هر فضای کاری، و یک استایل‌شیت کوچک که ردیف سرصفحهٔ همان workspace را رنگ
می‌کند — بدون fork کردن DSH و بدون تغییر در خودِ آن.

## امکانات

- **یک رنگ برای هر فضای کاری** — ردیف سرصفحه پس‌زمینهٔ رنگ‌گرفته، نوار تأکید رنگی و آیکون پوشهٔ
  رنگی می‌گیرد؛ نشست‌های زیر آن دست‌نخورده می‌مانند.
- **پالت رنگ داخلی** — رنگ‌های آماده به‌همراه فیلد رنگ دلخواه `#rrggbb`؛ هیچ پنجرهٔ رنگ
  سیستم‌عامل باز نمی‌شود.
- **صفحهٔ تنظیمات** — تنظیمات → **رنگ فضاهای کاری** فهرست همهٔ workspaceها را با رنگ فعلی، حذف
  رنگ برای هر ردیف و «پاک کردن همه رنگ‌ها» نشان می‌دهد.
- **تم روشن و تاریک** — فقط از توکن‌های تم هاست (`--dsw-alias-*`) استفاده می‌کند.
- **ذخیرهٔ محلی مرورگر**، مثل ترتیب نمایش خود نوار کناری: انتخاب در `localStorage` می‌ماند و به
  حالت Host نیازی ندارد.
- **به‌روزرسانی سبک** — ذخیره‌سازی با debounce، رندر یک‌بار در هر فریم و ویرایش قاعده‌ها با CSSOM
  به‌جای جایگزینی استایل‌شیت؛ بنابراین انتخاب رنگ برای CPU و GPU سبک است.
- **چرخهٔ تمیز** — غیرفعال کردن باندل، استایل‌شیت، صفحهٔ تنظیمات و آیکون ناوبری را حذف می‌کند.

## نصب

مخزن را کلون کنید و پوشه را به‌عنوان باندل نصب کنید:

```
git clone https://github.com/Pourii83/dsh-workspace-colors.git
plugin_manager install_bundle  (target: <path>/dsh-workspace-colors)
```

یا از رابط Harness: تنظیمات → پلاگین‌ها → نصب باندل از این پوشه. بعد از نصب، صفحهٔ تنظیمات زیر
«رنگ فضاهای کاری» ظاهر می‌شود.

## نحوهٔ کار

- **بخش Client** (`client.js`): فهرست فضاهای کاری را از هوک `useWorkspaces` اسلات نوار کناری
  می‌خواند (و در صورت نبود آن، از ردیف‌های رندرشدهٔ نوار کناری)، صفحهٔ تنظیمات را در اسلات
  `settings.section` و آیکون ناوبری را در `settings.section.icon` ثبت می‌کند، و یک استایل‌شیت
  متعلق به پلاگین نگه می‌دارد که ردیف‌های `[data-row-key="workspace:<workspaceId>"]` را رنگ
  می‌کند.
- **بخش Host** (`index.js`): خالی. این قابلیت در مرورگر ذخیره می‌شود، مثل ترتیب نمایش نوار
  کناری که خود DSH به‌صورت محلی نگه می‌دارد.
- **ذخیره‌سازی**: نگاشت `workspaceId → #rrggbb` در `localStorage` همین مرورگر با کلید
  `dsh.workspace-colors.v1` ذخیره می‌شود. با بازخوانی صفحه و ری‌استارت Harness روی همان مبدأ
  رابط وب باقی می‌ماند؛ مبدأ متفاوت یعنی شروع بدون رنگ.
- استایل‌ها فقط از توکن‌های تم (`--dsw-alias-*`) استفاده می‌کنند، پس در تم روشن و تاریک
  هم‌خوان هستند.

## کارایی

هر تغییر رنگ بدون کار سراسری به‌ازای هر رویداد انجام می‌شود:

- انتخابگر رنگ یک پالت درون‌برنامه‌ای به‌همراه فیلد هگز است، نه `<input type=color>` بومی؛
  بنابراین هیچ پنجرهٔ رنگ سیستم‌عامل باز نمی‌شود و جریان پیوستهٔ رویدادهای بومی هم دریافت
  نمی‌شود؛
- نوشتن رنگ‌ها در `localStorage` با تأخیر ۲۵۰ میلی‌ثانیه (debounce) انجام می‌شود؛
- انبار رنگ‌ها و مشترکان React حداکثر یک‌بار در هر فریم (`requestAnimationFrame`) به‌روز می‌شوند
  و ردیف‌های memo‌شده فقط ردیف تغییرکرده را دوباره رندر می‌کنند؛
- استایل‌شیت ردیف‌ها از طریق CSSOM ویرایش می‌شود (برای هر فضای کاری یک قاعده و به‌روزرسانی
  درجای اعلان‌ها) و دیگر متن کل `<style>` جایگزین نمی‌شود؛ جایگزینی متن باعث بی‌اعتبار شدن
  استایل کل سند در هر رویداد می‌شد و همان چیزی بود که تغییر پالت را سنگین می‌کرد؛
- رنگ‌آمیزی مجدد سایدبار هم با تأخیر ۱۵۰ میلی‌ثانیه‌ای بعد از توقف تغییرات انجام می‌شود تا
  انبوهی از تغییرات فقط یک بازرسم ایجاد کند؛
- افزودن/حذف یک رنگ فقط یک‌بار فهرست قاعده‌های کوچک را بازمی‌سازد و تغییر مقدار صرفاً اعلان‌ها
  را بازنویسی می‌کند؛
- فهرست فضاهای کاری از snapshot واکنشی می‌آید، پس تا وقتی snapshot در دسترس است هیچ پیمایش
  دوره‌ای DOM اجرا نمی‌شود.

## سازگاری

رنگ‌آمیزی ردیف‌ها به ویژگی پایدار `data-row-key="workspace:<id>"` و پسوندهای کلاس
`folder`/`title` که `dsh-client-ui-workspace` رندر می‌کند وابسته است. اگر نسخه‌ای از DSH آن‌ها را
تغییر دهد، صفحه و رنگ‌های ذخیره‌شده کار می‌کنند ولی ردیف‌ها رنگ نمی‌گیرند — چیز دیگری خراب
نمی‌شود. با `plugin_manager remove_bundle` همهٔ استایل‌ها، صفحه و آیکون حذف می‌شوند.

## فایل‌ها

- `package.json` — مانیفست باندل (`dsh.bundle.patch` و `dsh.client`).
- `cordis.patch.yml` — ردیف `workspace-colors` را در Loader درج می‌کند.
- `index.js` — بخش Host خالی.
- `client.js` — صفحهٔ تنظیمات، پالت رنگ، انبار رنگ‌ها، استایل‌شیت ردیف‌ها.
- `locale/{en,fa}.json` — عنوان و توضیح برای Plugin Manager.
- `icon.svg` — آیکون پالت رنگ.
